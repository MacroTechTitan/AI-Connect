# What is AI Connect?

AI Connect is a SaaS platform that helps you provision, integrate, and manage full-stack projects. Instead of manually wiring together GitHub repos, hosting on Render, authentication with Auth0, and payments with Stripe, AI Connect does it all through a single interface — Project Genesis.

## Who it's for

- **Solo founders** shipping products fast
- **Small teams** who need production-grade infrastructure without hiring a DevOps team
- **Anyone** building apps that need authentication, payments, or repo management

## What you get

- **Project Genesis** — one-click provisioning: GitHub repo + Supabase database + Render web service, wired together and ready to deploy
- **Integrations** — connect your Auth0 tenant, Stripe account, WordPress site, GitHub org, and more
- **Auto-wiring** — when you provision a project, AI Connect can automatically create Auth0 applications, Stripe Connect accounts, GitHub repos in your org, and sync all the credentials to your Render service

## Free vs Pro

AI Connect has two tiers:

- **Free** ($0/month) — 2 integrations, 1 project, WordPress + SendGrid connectors
- **Pro** ($49/month) — unlimited integrations, unlimited projects, all connectors including OpenClaw, Auth0, Stripe, GitHub

See [Understanding tiers](#understanding-tiers) for details.
